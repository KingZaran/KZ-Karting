# Custom icons (PNG)

Same file name as the id. Transparent PNGs, roughly square (maps are about 3:2). Missing files fall back to the built-in art.

- `chars/<character id>.png` - e.g. `chars/mario.png`, `chars/donkey-kong.png`
- `maps/<track id>.png` - e.g. `maps/circuit.png` (ids are in `js/tracks.js`)
- `karts/<kart id>.png` - standard, hotrod, cruiser, buggy, bumper, tank
- `wheels/<wheel id>.png` - standard, slick, mud, roller
- `items/<item id>.png` - see `js/sprites.js`
