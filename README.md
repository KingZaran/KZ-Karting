# Turbo Realms Kart
Browser kart racer (three.js, no build step). Open `index.html` via any static server, or deploy with GitHub Pages.

## Roadmap
1. [x] Scaffold + drivable prototype with bots
2. [ ] Race options menu (bot count, laps, items on/off, engine class) + track voting/random
3. [ ] Items (full 8 Deluxe set, original art) + item boxes
4. [ ] Multiple tracks with themed zones (cave kingdom, rainy bug city, ink arena, endless yellow halls, brawler stage…)
5. [ ] Realism pass: better physics, shadows, post-processing, audio
6. [ ] GitHub Pages deploy + Supabase online multiplayer
